# Hopinn — презентация для отелей

Презентация проекта Hopinn для отелей.

[Открыть презентацию](https://dasmirnov-git.github.io/dimas_pub_/hopinn-hotels/)

На слайде «Условия» доступен калькулятор цены, скидки клиенту и сервисного сбора. Он показывает распределение цены и полную скидку отеля. Скачиваемая PDF-версия сохраняет статичную диаграмму.
